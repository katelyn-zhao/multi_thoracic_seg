# Automated ROI Placement in MRI-PDFF Phantoms: A Deep Learning Approach to Quality Control

## Background

Rigorous clinical and research magnetic resonance imaging proton density fat fraction (MRI-
PDFF) liver protocols now frequently include quality control phantoms placed beneath patients during
scanning. Processing of phantom data is currently performed manually, requiring operators to place regions of
interest (ROIs) on parametric MRI-PDFF maps correctly, an error-prone and time-intensive process. The
purpose of this study was to automate ROI placement in MRI-PDFF quality-control phantoms using deep
learning.
